# Craftbound（仮称）MOD 概要

## 1. 概要

Craftbound（仮称）は、Minecraftの生活・生産系コンテンツを拡張し、`Pufferfish's Skills` のスキルツリーと連携させるための自作MODである。

単に「農家」「料理人」「鍛冶師」「探検家」などの職業を追加するのではなく、農業、料理、鍛冶、素材加工、ポーション・錬金、フィールド探索といった行動に成長要素を与え、プレイヤーごとの専門性を生み出すことを目的とする。

本MODは、3か月程度の期間限定Minecraftサーバーで使用することを前提としている。プレイヤー間取引が成立する経済環境と、次のような冒険・生産ループの形成を目指す。

```text
フィールド探索・ダンジョン探索・ボス討伐
    ↓
希少素材・専用鋳型・作物などを入手
    ↓
探検家が希少資源を発見し、冒険者がボス素材を獲得
    ↓
農家・料理人・鍛冶師などが加工
    ↓
高品質な料理・装備・消耗品を生産
    ↓
販売・使用
    ↓
より強いボスや新しい地域へ挑戦
```

---

## 2. 基本方針

### 2.1 生産職に専門性を持たせる

プレイヤーがすべての生産を同じ効率で行える状態にはせず、スキルの育成によって得意分野が分かれる設計とする。

想定する分野は以下のとおり。

- 農業
- 料理
- 鍛冶
- 非金属素材の加工
- ポーション・錬金
- 探索

ただし、スキル未取得者を単純に操作不能にするような強い制限は、可能な限り避ける。スキルは主に次の要素へ影響させる。

- 作業の成功率
- 加工精度
- 品質
- 作業時間
- 素材消費量
- ミニゲームの難易度
- 特殊効果や副産物の発生率

高度なレシピを完全にスキルで制限するか、低スキルでも低品質・高失敗率で挑戦可能にするかは、今後決定する。

### 2.2 自動化と手作業を競合させない

`Create` は弱体化せず、大量生産や物流を担当させる。

一方、本MODの専門職は、高品質品、希少素材、上位料理、ボス装備など、プレイヤー本人の操作やスキルを必要とする高付加価値品を担当する。

```text
Create
- 大量生産
- 標準品質
- 日常的な原料・食品
- 搬送・加工ライン

専門職
- 高品質品
- 希少作物
- 高級料理・バフ料理
- ボス素材装備
- 依頼品・限定品
```

Createによる自動農業や通常加工は残しつつ、上位レシピだけは専用作業台でのプレイヤー操作を必須にする。

### 2.3 完全自由な装備合成は採用しない

`Tinkers' Construct` のように、あらゆる素材と部品を自由に組み合わせる方式は、初期実装では採用しない。

装備はあらかじめ定義された固定アイテムとし、各装備に必要な専用中間パーツを加工して組み立てる方式とする。

これにより、次の問題を抑える。

- 組み合わせ数の爆発
- 動的な見た目生成の複雑化
- バランス調整の困難化
- 他MOD装備との競合
- 2か月の運営期間に対して過剰な実装量になること

## 3. 想定環境

現時点での前提は以下のとおり。

- Minecraft Forge 1.20.1
- サーバー運営期間：約3か月
- `Pufferfish's Skills` を使用
- `Create` 本体を使用
- Create拡張MODは原則として増やさない
- 経済システムとして `Lightman's Currency` の利用を想定
- 食事の多様性に需要を持たせるため、`Diet` との連携を想定
- 敵・ボス・ダンジョンそのものは、既存の冒険MODを活用する
- `Cataclysm` や `Twilight Forest` などの素材・装備との連携を想定

## 4. スキルシステム連携

本MODの各生産・探索行動を、`Pufferfish's Skills` の対応するスキルツリーへ接続する。

農家と料理人は別々の職業として扱う可能性がある一方で、育成上は同じスキルツリーへ統合する可能性もある。つまり、表示上や経済上の役割は分けつつ、農業と料理を一つの生活・食料系スキルツリーとして成長させる構成も候補とする。正式な分割方法は未決定である。

想定例：

| 行動 | 関連スキル |
|---|---|
| 作物の収穫 | 農業（料理との共通化候補） |
| 高品質作物の生産 | 農業（料理との共通化候補） |
| 専用作業台での調理 | 料理（農業との共通化候補） |
| 金属の溶解・鋳造 | 鍛冶 |
| ハンマーによる鍛造 | 鍛冶 |
| 木材・骨・皮などの加工 | 加工・鍛冶 |
| ポーションや薬品の作成 | 錬金・ポーション |
| 新しいバイオームや構造物への到達 | 探索 |
| 希少作物・地域素材・発見物の収集 | 探索 |

スキルによって、単純な数値上昇だけでなく、実際の加工操作を扱いやすくする。

例：

- 硬い素材でも狙った形に削りやすくなる
- 鍛造時の目盛りや現在強度を読み取りやすくなる
- 加工用道具の耐久消費を抑えられる
- 素材特性や完成後の品質を詳しく確認できる
- 加工物の破損が近いことを音から早く察知できる
- 調理の失敗率が下がる
- 同じ品質を作るために必要な操作回数が減る

## 5. 探検家

### 5.1 役割

探検家は、戦闘そのものよりも、さまざまなフィールドを巡り、新しい場所や資源を発見することを楽しむプレイヤー向けの職業である。

主な活動は以下を想定する。

- 未訪問のバイオームや地域を巡る
- ダンジョン、遺跡、構造物を発見する
- 野生作物や希少植物を探す
- 地域限定素材や特殊資源を持ち帰る
- 専用鋳型やルート品を発見する
- 他の職業が必要とする素材の入手経路を開拓する

探検家は冒険コンテンツに関わるが、戦闘職ではない。敵の討伐能力を主な成長軸にはせず、「遠くへ行くこと」「見つけること」「持ち帰ること」に価値を持たせる。

### 5.2 スキルの方向性

探索スキルは、行動を強く制限するのではなく、探索の快適性や発見効率を高める方向とする。

候補となる効果：

- 新しいバイオームや構造物を発見した際の経験値獲得
- 希少作物や特殊資源を見つけやすくする補助
- 採取時に追加素材を得る確率の上昇
- 長距離移動に関する軽微な補助
- 地図、コンパス、探索道具の強化
- 発見済み地点や資源情報を共有しやすくする機能
- 地域限定素材の品質や採取量への補正

単純な移動速度の大幅上昇や、戦闘能力の恒常的な強化は避ける。探検家だけが特定地域へ入れるような強い排他制限も、原則として設けない。

### 5.3 他職業との関係

探検家は、各生産職へ希少素材と発見情報を供給する。ボス討伐や高難度戦闘を担当する冒険者とは役割を分け、探検家は戦わなくても成立する探索中心のロールとする。

```text
探検家
- 野生作物・種・苗 → 農家
- 希少食材・地域素材 → 料理人
- 希少鉱石・地域素材・専用鋳型 → 鍛冶師
- 薬草・Mob素材 → 錬金担当
```

これにより、戦闘を好まないプレイヤーでも、フィールド探索を通じてサーバー経済と攻略進行へ参加できるようにする。

## 6. 農業システム

### 6.1 新規作物

独自の作物を追加する。

作物には、通常の農地で育てられるものだけでなく、探索によって最初の種や苗を入手するものを含める。

想定する入手方法：

- 特定バイオームに野生状態で生成
- 他MODが追加するバイオームに生成
- ダンジョンのチェストから入手
- ボスや特殊Mobから副産物として入手
- 特定地域でのみ得られる希少素材として配置

他MODのバイオームへ生成する場合は、バイオームIDを大量に直接指定するのではなく、可能な限りバイオームタグを利用する。

### 6.2 探索と栽培の二層構造

一度見つけた作物を無制限に栽培できるだけでは、探検家が継続してフィールドを巡る価値が早期に失われる可能性がある。

そのため、次のような二層構造を検討する。

- 栽培可能な通常作物
- 野生個体からしか得られない希少副産物

この方式であれば、農家による安定生産と、探検家による継続的な採取需要を両立できる。

### 6.3 品質

農作物や加工品には、5段階程度の品質を設定する。

品質は次の要素に影響する想定である。

- 売却価格
- 回復量
- 料理完成品の品質
- バフの強さ・持続時間
- 加工時の成功率
- 高級レシピの材料条件

品質ごとに別スタックとなるため、品質段階は増やしすぎない。

### 6.4 腐敗・品質劣化

時間経過による腐敗や品質劣化も検討しているが、各アイテムに個別の取得時刻を保存すると、同じ品質のアイテム同士でもスタックできなくなる。

そのため、以下の方針を守る。

- アイテムごとの個別タイムスタンプは持たせない
- 1スタック内のアイテムは同じ品質状態として扱う
- 品質は最大5段階程度に固定する
- インベントリ内のアイテム種類が無制限に増えないようにする

腐敗方式としては、スタック単位での低確率劣化や、劣化した食品が周囲へ影響する「腐敗の伝染」のような仕組みが候補である。

ただし、自然さ、処理負荷、プレイヤーの納得感を含めて、具体的な方式は未決定である。

## 7. 料理システム

### 7.1 専用調理ブロック

専用調理ブロックにはGUIを持たせる。

基本的な処理の流れ：

1. GUI内のグリッドへ材料を配置する
2. プレイヤーが調理開始ボタンを押す
3. ボタンを押したプレイヤーのスキルや状態を判定する
4. 一定時間かけて調理する
5. 成功・失敗・品質を決定する
6. 完成品を出力する

上位料理では、材料を搬入するだけで自動的に完成しないようにする。

Createは材料の搬送や通常素材の生産には利用できるが、上位料理の開始処理はプレイヤー本人が行う。

### 7.2 料理の役割

料理は、単なる満腹度回復アイテムではなく、経済と冒険を支える消耗品とする。

想定する分類：

- 日常食
- 高品質料理
- 高級料理
- 冒険用バフ料理
- ボス戦用料理
- 特定の食品群を補う料理
- 注文・依頼向け料理

`Diet` と組み合わせ、複数の食品群を食べる意味を持たせることで、料理人や農家への継続的な需要を作る。

## 8. 鍛冶システム

### 8.1 基本工程

金属装備は、単一のクラフトレシピで完成させず、複数の加工工程を通す。

想定工程：

```text
素材・鉱石・ボス素材
    ↓
るつぼで溶解
    ↓
溶鉱炉で加熱・温度管理
    ↓
適温で取り出す
    ↓
鋳型へ流し込む
    ↓
冷却して粗加工パーツを作る
    ↓
鍛造専用作業台へ移す
    ↓
ハンマーで鍛造ミニゲーム
    ↓
金属パーツ完成
    ↓
非金属パーツと組み立て
    ↓
完成装備
```

### 8.2 専用鋳型

通常装備には汎用鋳型を使用できるが、ボス素材装備には専用鋳型を必要とする。

専用鋳型は、ダンジョンのルートチェストなどから入手する。

これにより、ボスを倒した直後に素材だけで装備を完成させるのではなく、探索と生産を組み合わせた進行にできる。

例：

```text
Ignisの専用インゴット
    ↓
専用鋳型へ流し込む
    ↓
専用の剣刃パーツを作る
    ↓
柄やその他の加工パーツと組み立てる
    ↓
Ignis系装備を完成させる
```

### 8.3 他MOD装備との連携

`Cataclysm` や `Twilight Forest` などの装備についても、本MODの加工工程を通して作れるようにすることを検討する。

ただし、素材を自由に組み合わせて新しい武器を生成するのではなく、既存装備に対応する専用レシピだけを追加する。

```text
他MODのボス素材
    ↓
本MODの専用中間パーツ
    ↓
定義済みの完成装備
```

### 8.4 品質判定

完成品の品質は、素材品質だけでなく、各加工工程の結果から決定する。

品質へ影響する候補：

- 加熱温度
- 取り出すタイミング
- 鋳造時の状態
- 鍛造ミニゲームの精度
- 削り加工の形状一致率
- 使用した道具

プレイヤーのスキル値は品質へ直接加算しない。操作支援によって同じ加工を再現しやすくなった結果だけ、間接的に品質へ影響する。

品質によって、攻撃力を単純に大幅上昇させすぎないようにする。

主な差としては、耐久値、修理効率、特殊効果の発動率、軽微な性能補正、売却価格などを想定する。

## 9. 非金属素材の加工

### 9.1 対象素材

装備の柄、持ち手、装飾、革部品など、金属以外の部品も加工工程を持たせる。

対象例：

- 木材
- 骨
- 角
- 革
- モンスター素材
- 特殊な植物素材

### 9.2 削りミニゲーム

非金属素材の加工では、素材を削って理想形状へ近づけるミニゲームを検討する。

想定操作：

1. 専用作業台へ素材を置く
2. 加工用アイテムを持って右クリックする
3. ミニゲームを開始する
4. 左クリックを押しながら、削りたい部分をドラッグする
5. 操作した位置を中心に素材が削れる
6. 理想形状に近いほど高品質になる

素材プロファイルの除去量と道具負荷によって、削りやすさと加工道具の消耗を変化させる。

精密成形スキルが高いほど、細かいグリッドと狭いブラシを使用でき、狙った形状へ近づけやすくなる。

### 9.3 内部表現

削られた状態は、グリッド状の配列として保持する案がある。

単純な `boolean` 配列ではなく、`float` または `int` の配列を使い、各セルの残存量や透明度を表現する。

```text
0.0 = 完全に削られている
1.0 = 完全に残っている
```

この配列をGUI上の描画へ反映し、素材が徐々に削れていく見た目を作る。

初期実装では、ブロック本体のテクスチャを動的変更するより、専用GUI内で描画する方針が現実的である。

削りミニゲームは本MODの特徴になり得る一方、実装負荷が高い場合は簡略化または後回しにする。

## 10. ポーション・錬金システム

ポーション・錬金分野も、`Pufferfish's Skills` と連携する生活系スキルとして追加候補に含まれる。

想定する方向性：

- 独自素材を利用する薬品
- 探索で入手した植物やMob素材の加工
- 品質による効果時間・効果量の変化
- 調合成功率や副作用へのスキル影響
- 冒険前に購入・準備する消耗品としての需要

具体的な作業台、ミニゲーム、レシピ体系は未決定である。

---

## 11. 経済システムにおける役割

本MODは、プレイヤー間取引の対象となる高付加価値品を増やす役割を持つ。

主な供給関係：

| プレイヤー | 主な供給物 |
|---|---|
| 探検家 | 希少植物、地域素材、専用鋳型、ダンジョンの発見物 |
| 冒険者 | ボス素材、戦闘報酬、高難度ダンジョン素材 |
| 農家 | 高品質作物、特殊作物、料理材料 |
| 料理人 | 高級料理、バフ料理、依頼品 |
| 鍛冶師 | ボス装備、武器部品、防具、修理・再加工 |
| 錬金担当 | ポーション、薬品、戦闘用消耗品 |

農家は食料インフラを担うため、比較的安定した収入を得やすい。

そのため、経済全体ではガチャ、装飾、コスメ、土地、ダンジョン挑戦費、装備製造費など、本MOD外も含めた通貨の消費先が必要になる。

本MOD単体ですべての経済問題を解決するのではなく、専門職間の取引材料と消耗品需要を増やすことを主目的とする。

## 12. 他MODとの役割分担

### Pufferfish's Skills

- スキルツリーと成長要素を担当
- 本MODの生産行動や品質判定と接続

### Create

- 大量生産
- 原料生産
- 物流
- 標準品質品

上位料理、ボス装備、ミニゲーム加工などは自動化させない。

### Diet

- 食品の種類に継続的な需要を作る
- 農家・料理人の生産物が一種類へ偏ることを防ぐ

### Cataclysm / Twilight Forest など

- ボス、ダンジョン、戦闘、希少素材を担当
- 本MODは素材加工と装備製造を担当

### Lightman's Currency

- プレイヤー間取引や店舗を担当
- 本MODの高品質品・装備・料理の販売に利用

実装が必要になる主な要素は以下のとおり。

- 独自アイテム

## 14. 現時点での確定事項

- 生活・生産系行動をPufferfish's Skillsへ接続する
- 農業、料理、鍛冶、探索を主要分野とする
- 探検家は戦闘職ではなく、フィールド巡回・発見・採取を中心とする
- 農家と料理人は、役割を分けつつスキルツリーを共通化する可能性がある
- ポーション・錬金も追加候補に含める
- Createは弱体化せず、大量生産担当として残す
- 上位生産物にはプレイヤー操作を要求する
- 新規作物を追加する
- 特定バイオームや他MODバイオームに野生作物を生成する
- 品質は5段階程度に抑える
- アイテムごとの個別タイムスタンプは使用しない
- 装備は固定レシピ・固定アイテム方式とする
- ボス装備には専用中間パーツや専用鋳型を使用する
- 専用鋳型はダンジョン報酬として入手させる
- 鍛冶は複数工程に分ける
- 2か月の運営期間で遊び切れない程度の生産・冒険ループを目指す
