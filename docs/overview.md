# Craftbound（仮称）MOD 概要

## 1. 概要

Craftbound（仮称）は、Minecraftの生活・生産系コンテンツを拡張し、`Pufferfish's Skills` のスキルツリーと連携させるための自作MODである。

単に職業名だけを追加するのではなく、食料生産者、鍛冶師、探検家などの役割を、農耕、畜産・酪農、料理、鍛冶、素材加工、ポーション・錬金、フィールド探索といった実際の行動へ接続し、プレイヤーごとの専門性を生み出すことを目的とする。

本MODは、3か月程度の期間限定Minecraftサーバーで使用することを前提としている。プレイヤー間取引が成立する経済環境と、次のような冒険・生産ループの形成を目指す。

```text
フィールド探索・ダンジョン探索・ボス討伐
    ↓
希少素材・専用鋳型・作物などを入手
    ↓
探検家が希少資源を発見し、冒険者がボス素材を獲得
    ↓
食料生産者・鍛冶師などが加工
    ↓
高品質な料理・装備・消耗品を生産
    ↓
販売・使用
    ↓
より強いボスや新しい地域へ挑戦
```

---

## 2. 基本方針

### 2.1 生産職に専門性を持たせる

プレイヤーがすべての生産を同じ効率で行える状態にはせず、スキルの育成によって得意分野が分かれる設計とする。

想定する分野は以下のとおり。

- 農業
- 畜産・酪農
- 料理
- 鍛冶
- 非金属素材の加工
- ポーション・錬金
- 探索

ただし、スキル未取得者を単純に操作不能にするような強い制限は、可能な限り避ける。スキルは主に次の要素へ影響させる。

- 作業の成功率
- 加工精度
- 品質
- 作業時間
- 素材消費量
- ミニゲームの難易度
- 特殊効果や副産物の発生率

食料生産者については、スキル未取得者も通常の栽培、食事、バニラ料理および完成済み設備の利用を行える。専門性は、収量、品質、処理時間、専用レシピ、スキル補正および専用設備によって表現する。例外として、食料生産者が管理する家畜の繁殖は牧畜ブロックの管理範囲内でのみ成立する。

食料生産者専用の料理レシピは、レシピ研究ランクによって解放する。完成した料理や設備の譲渡・利用は制限しない。他職業の高度レシピをどの程度スキルで制限するかは、各職業仕様で決定する。

### 2.2 自動化と手作業を競合させない

`Create` は弱体化せず、大量生産や物流を担当させる。

一方、本MODの専門職は、高品質品、希少素材、上位料理、ボス装備など、プレイヤー本人の操作やスキルを必要とする高付加価値品を担当する。

```text
Create
- 大量生産
- スキル補正なしの品質
- 日常的な原料・食品
- 搬送・加工ライン

専門職
- 高品質品
- 希少作物
- 高級料理・バフ料理
- ボス素材装備
- 依頼品・限定品
```

Createによる自動農業や通常加工は残す。食料生産者関連の自動処理はスキルなしの処理として扱い、保存食系列の自動加工品は低品質へ固定する。上位料理などの`manual_only`レシピだけは、対応スキルを持つプレイヤーの開始操作を必須にする。

### 2.3 完全自由な装備合成は採用しない

`Tinkers' Construct` のように、あらゆる素材と部品を自由に組み合わせる方式は、初期実装では採用しない。

装備はあらかじめ定義された固定アイテムとし、各装備に必要な専用中間パーツを加工して組み立てる方式とする。

これにより、次の問題を抑える。

- 組み合わせ数の爆発
- 動的な見た目生成の複雑化
- バランス調整の困難化
- 他MOD装備との競合
- 3か月の運営期間に対して過剰な実装量になること

## 3. 想定環境

現時点での前提は以下のとおり。

- Minecraft Forge 1.20.1
- サーバー運営期間：約3か月
- `Pufferfish's Skills` を使用
- `Create` 本体を使用
- Create拡張MODは原則として増やさない
- 経済システムとして `Lightman's Currency` の利用を想定
- 食事の多様性に需要を持たせるため、`Diet` との任意連携を想定。未導入でもMOD本体が動作する構成とする
- 敵・ボス・ダンジョンそのものは、既存の冒険MODを活用する
- `Cataclysm` や `Twilight Forest` などの素材・装備との連携を想定

## 4. スキルシステム連携

本MODの各生産・探索行動を、`Pufferfish's Skills` の対応するスキルツリーへ接続する。

農耕、畜産・酪農および料理は食料生産者として統合し、1つの共通経験値、共通レベル、共通スキルポイントを使用する。食料生産者のスキルツリーは、1つのタブ内で農耕、畜産・酪農、料理の3方向へ分岐する。

想定例：

| 行動 | 関連スキル |
|---|---|
| 作物の収穫 | 食料生産者・農耕分岐 |
| 高品質作物の生産 | 食料生産者・農耕分岐 |
| 家畜の管理・繁殖・屠畜 | 食料生産者・畜産・酪農分岐 |
| 専用設備での加工・調理 | 食料生産者・料理分岐 |
| 金属の溶解・鋳造 | 鍛冶 |
| ハンマーによる鍛造 | 鍛冶 |
| 木材・骨・皮などの加工 | 加工・鍛冶 |
| ポーションや薬品の作成 | 錬金・ポーション |
| 新しいバイオームや構造物への到達 | 探索 |
| 希少作物・地域素材・発見物の収集 | 探索 |

スキルによって、単純な数値上昇だけでなく、実際の加工操作を扱いやすくする。

例：

- 硬い素材でも狙った形に削りやすくなる
- 鍛造時の目盛りや現在強度を読み取りやすくなる
- 加工用道具の耐久消費を抑えられる
- 素材特性や完成後の品質を詳しく確認できる
- 加工物の破損が近いことを音から早く察知できる
- 調理の失敗率が下がる
- 同じ品質を作るために必要な操作回数が減る

## 5. 探検家

### 5.1 役割

探検家は、戦闘そのものよりも、さまざまなフィールドを巡り、新しい場所や資源を発見することを楽しむプレイヤー向けの職業である。

主な活動は以下を想定する。

- 未訪問のバイオームや地域を巡る
- ダンジョン、遺跡、構造物を発見する
- 野生作物や希少植物を探す
- 地域限定素材や特殊資源を持ち帰る
- 専用鋳型やルート品を発見する
- 他の職業が必要とする素材の入手経路を開拓する

探検家は冒険コンテンツに関わるが、戦闘職ではない。敵の討伐能力を主な成長軸にはせず、「遠くへ行くこと」「見つけること」「持ち帰ること」に価値を持たせる。

### 5.2 スキルの方向性

探索スキルは、行動を強く制限するのではなく、探索の快適性や発見効率を高める方向とする。

候補となる効果：

- 新しいバイオームや構造物を発見した際の経験値獲得
- 希少作物や特殊資源を見つけやすくする補助
- 採取時に追加素材を得る確率の上昇
- 長距離移動に関する軽微な補助
- 地図、コンパス、探索道具の強化
- 発見済み地点や資源情報を共有しやすくする機能
- 地域限定素材の品質や採取量への補正

単純な移動速度の大幅上昇や、戦闘能力の恒常的な強化は避ける。探検家だけが特定地域へ入れるような強い排他制限も、原則として設けない。

### 5.3 他職業との関係

探検家は、各生産職へ希少素材と発見情報を供給する。ボス討伐や高難度戦闘を担当する冒険者とは役割を分け、探検家は戦わなくても成立する探索中心のロールとする。

```text
探検家
- 野生作物・種・苗・希少食材 → 食料生産者
- 希少鉱石・地域素材・専用鋳型 → 鍛冶師
- 薬草・Mob素材 → 錬金術師
```

これにより、戦闘を好まないプレイヤーでも、フィールド探索を通じてサーバー経済と攻略進行へ参加できるようにする。

## 6. 食料生産者：農耕・品質・保存

### 6.1 初期栽培対象と新規作物

初期実装では、次のバニラ作物を対象に栽培、成長管理、収穫、再植え付け、増産、品質管理および備蓄を実装する。

- 小麦
- ニンジン
- ジャガイモ
- ビートルート
- カボチャ
- スイカ
- サトウキビ
- カカオ
- スイートベリー
- グロウベリー

ネザーウォートは食料生産者の対象外とし、錬金術師が担当する。新規作物を追加する構想は維持し、上記バニラ作物の実装とプレイテストが完了した後に設計・実装へ着手する。この順序は実装優先度を示すものであり、新規作物の追加を取りやめるものではない。

追加する新規作物には、探索によって最初の種や苗を入手するものを含める。想定する入手方法は次のとおり。

- 特定バイオームに野生状態で生成
- 他MODが追加するバイオームに生成
- ダンジョンのチェストから入手
- ボスや特殊Mobから副産物として入手
- 特定地域でのみ得られる希少素材として配置

他MODのバイオームへ生成する場合は、バイオームIDを大量に直接指定するのではなく、可能な限りバイオームタグを利用する。

### 6.2 探索と栽培の二層構造

一度見つけた作物を無制限に栽培できるだけでは、探検家が継続してフィールドを巡る価値が早期に失われる可能性がある。

そのため、次のような二層構造を検討する。

- 栽培可能な通常作物
- 野生個体からしか得られない希少副産物

この方式であれば、食料生産者による安定生産と、探検家による継続的な採取需要を両立できる。

### 6.3 品質

食料生産者が扱う材料、中間素材、直接食べられる食料、料理および保存食には、次の4状態を設定する。

ただし、怪しげなシチューや金のリンゴなど、バニラの状態効果付き食品は錬金術師の担当とし、食料生産者の品質対象から除外する。食料生産者固有の各ロール向け料理はこの除外に含めない。

| 内部値 | 表示名 | 利用 |
|---|---|---|
| 3 | 高品質 | 食用・加工・給餌可能 |
| 2 | 標準品質 | 食用・加工・給餌可能 |
| 1 | 低品質 | 食用・加工・給餌可能 |
| 0 | 腐敗 | 食用・加工・給餌不可。堆肥化のみ可能 |

品質は満腹度、隠し満腹度、バフ持続時間および加工後の完成品質へ影響する。Dietの栄養値と効果レベル自体は品質で変化させない。

加工品の基準完成品質には、使用した品質対象材料のうち最も低い品質を使用する。手動の最終加熱で条件を満たした場合だけ、使用材料の最高品質を上限として最大1段階上昇できる。

### 6.4 腐敗・品質劣化

品質は、対象スタックが読み込まれている時間の経過によって、高品質、標準品質、低品質、腐敗の順に1段階ずつ低下する。

| 分類 | 1段階あたりの基礎維持時間 | 高品質から腐敗まで |
|---|---:|---:|
| 料理 | 20分 | 60分 |
| 材料 | 120分 | 6時間 |
| 保存食 | 240分 | 12時間 |

各スタックは、現在品質、現在品質における基礎残り時間、最後に時間計算した時刻および最後に適用した保存倍率を保持する。個々のアイテムには別々の取得時刻を持たせない。

同一アイテムかつ同一品質で、その他の効果情報に互換性があるものだけを統合できる。統合時は短い方の基礎残り時間を採用する。

通常のインベントリ、チェスト、樽、シュルカーボックスおよび未対応コンテナでは保存倍率を1.0倍とする。FoodProducerの保存設備Iは3.0倍、保存設備IIは5.0倍とし、品質を回復させず、残り時間の消費速度だけを低下させる。両設備は27個の通常スロットを持つ独立した単ブロックとし、整理機能と品質別自動振り分けはMVP後の拡張候補とする。未読み込みチャンク、オフライン中のプレイヤーインベントリおよび地面に落ちたItem Entityでは品質時間を停止する。

### 6.5 農耕

耕地の最大肥沃度を100とし、通常作物の植え付け時に20を消費する。堆肥と骨粉から作る農業用肥料で肥沃度を回復する。骨粉を作物へ直接使用する即時成長効果は無効化する。

作物の成熟時間は植え付け時の生育管理ランクで確定し、収穫時には収量管理による追加生産物と、品質栽培による品質確率を判定する。自動植え付け・自動収穫ではスキル補正と経験値を付与しない。

食料生産者自身は低耐久の木製・石製クワを製作できる。鉄以上のクワと、範囲耕耘・植え付け・収穫・施肥機能は鍛冶師側の仕様へ委ねる。

### 6.6 畜産・酪農

対象はウシ、ブタ、ヒツジ、ニワトリ、ウサギおよびムーシュルームとする。牧畜ブロック1個につき1種類を、16×16×33ブロックの範囲で管理する。

牧畜ブロックは給餌、管理可能数、子どもの成長および繁殖条件を管理するが、繁殖自体はプレイヤーの手動操作を必須とする。完成した牧畜ブロックは譲渡可能で、所有権や専用アクセス制限を持たない。自動管理処理から食料生産者の経験値は発生させない。

## 7. 食料生産者：料理・加工

### 7.1 加工工程と設備

初期実装は、次の5工程で構成する。

| 工程 | 対応道具・設備 | 自動化の基本方針 |
|---|---|---|
| 切断 | 鍛冶師製の調理包丁＋食料生産者製の調理台 | 保存食用素材だけCreate自動化可能 |
| 粉砕 | 鍛冶師製の手回しミル | 手動のみ |
| 保存加工 | 鍛冶師製の乾燥器 | Create自動化可能 |
| 混合 | 食料生産者製の調理台 | 保存食I～VだけCreate自動化可能 |
| 加熱 | 鍛冶師製の調理鍋 | 手動のみ |

食料生産者関連レシピは、データ上で`create_low_quality`または`manual_only`の自動化方針を持つ。`create_low_quality`はCreateのデプロイヤーで開始できるが、出力は低品質固定でスキル補正と経験値を得られない。`manual_only`は実プレイヤーの開始操作を必要とする。FoodProducer加工設備はバニラのホッパーとドロッパーによる自動化へ対応しない。

料理ミニゲームはMVP対象外とし、手動・自動ともに操作評価を`成功`固定で中間素材へ継承する。操作評価データは将来拡張用に維持するが、MVPでは専用入力・採点・UIおよび操作評価による品質補正を行わない。

ゲーム結果、乱数、経験値および操作評価の確定はサーバー側を正とする。

### 7.2 料理の役割

料理は、単なる満腹度回復アイテムではなく、経済と冒険を支える消耗品とする。

想定する分類：

- 日常食
- 高品質料理
- 高級料理
- 冒険用バフ料理
- ボス戦用料理
- 特定の食品群を補う料理
- 注文・依頼向け料理

食料生産者は、高い満腹度・隠し満腹度とDiet栄養値を持つ長期携帯向けの保存食と、満腹でも使用できる少量生産の長時間バフ料理を提供する。完成品の譲渡・消費に食料生産者スキルや消費者のロールは要求しない。固有効果を持つ職業料理は同時に1種類だけ有効とし、同一料理は時間を更新できるが、別料理は効果終了または牛乳等による解除まで食べられない。

`Diet` と組み合わせ、穀物、野菜、果物、タンパク質、糖類の5カテゴリを材料から完成品へ継承することで、食料生産者の生産物へ継続的な需要を作る。保存食は職業料理よりDiet上昇量を高くし、品質によるDiet補正は行わない。Dietは任意依存とし、無効な場合も料理自体は通常どおり機能する。

FoodProducerの詳細仕様、アセット台帳、判断事項およびテスト状況は、[FoodProducer文書案内](occupations/foodproducer/README.md)を入口として参照する。

### 7.3 スキル構成

食料生産者は1つの共通経験値とスキルポイントを使用し、農耕、畜産・酪農、料理の3分岐へ配分する。料理分岐は、基礎加工、加工技術、品質調理およびレシピ研究で構成する。

## 8. 鍛冶システム

### 8.1 基本工程

金属装備は、単一のクラフトレシピで完成させず、複数の加工工程を通す。

想定工程：

```text
素材・鉱石・ボス素材
    ↓
るつぼで溶解
    ↓
溶鉱炉で加熱・温度管理
    ↓
適温で取り出す
    ↓
鋳型へ流し込む
    ↓
冷却して粗加工パーツを作る
    ↓
鍛造専用作業台へ移す
    ↓
ハンマーで鍛造ミニゲーム
    ↓
金属パーツ完成
    ↓
非金属パーツと組み立て
    ↓
完成装備
```

### 8.2 専用鋳型

通常装備には汎用鋳型を使用できるが、ボス素材装備には専用鋳型を必要とする。

専用鋳型は、ダンジョンのルートチェストなどから入手する。

これにより、ボスを倒した直後に素材だけで装備を完成させるのではなく、探索と生産を組み合わせた進行にできる。

例：

```text
Ignisの専用インゴット
    ↓
専用鋳型へ流し込む
    ↓
専用の剣刃パーツを作る
    ↓
柄やその他の加工パーツと組み立てる
    ↓
Ignis系装備を完成させる
```

### 8.3 他MOD装備との連携

`Cataclysm` や `Twilight Forest` などの装備についても、本MODの加工工程を通して作れるようにすることを検討する。

ただし、素材を自由に組み合わせて新しい武器を生成するのではなく、既存装備に対応する専用レシピだけを追加する。

```text
他MODのボス素材
    ↓
本MODの専用中間パーツ
    ↓
定義済みの完成装備
```

### 8.4 品質判定

完成品の品質は、素材品質だけでなく、各加工工程の結果から決定する。

品質へ影響する候補：

- 加熱温度
- 取り出すタイミング
- 鋳造時の状態
- 鍛造ミニゲームの精度
- 削り加工の形状一致率
- 使用した道具

プレイヤーのスキル値は品質へ直接加算しない。操作支援によって同じ加工を再現しやすくなった結果だけ、間接的に品質へ影響する。

品質によって、攻撃力を単純に大幅上昇させすぎないようにする。

主な差としては、耐久値、修理効率、特殊効果の発動率、軽微な性能補正、売却価格などを想定する。

## 9. 非金属素材の加工

### 9.1 対象素材

装備の柄、持ち手、装飾、革部品など、金属以外の部品も加工工程を持たせる。

対象例：

- 木材
- 骨
- 角
- 革
- モンスター素材
- 特殊な植物素材

### 9.2 削りミニゲーム

非金属素材の加工では、素材を削って理想形状へ近づけるミニゲームを検討する。

想定操作：

1. 専用作業台へ素材を置く
2. 加工用アイテムを持って右クリックする
3. ミニゲームを開始する
4. 左クリックを押しながら、削りたい部分をドラッグする
5. 操作した位置を中心に素材が削れる
6. 理想形状に近いほど高品質になる

素材プロファイルの除去量と道具負荷によって、削りやすさと加工道具の消耗を変化させる。

精密成形スキルが高いほど、細かいグリッドと狭いブラシを使用でき、狙った形状へ近づけやすくなる。

### 9.3 内部表現

削られた状態は、グリッド状の配列として保持する案がある。

単純な `boolean` 配列ではなく、`float` または `int` の配列を使い、各セルの残存量や透明度を表現する。

```text
0.0 = 完全に削られている
1.0 = 完全に残っている
```

この配列をGUI上の描画へ反映し、素材が徐々に削れていく見た目を作る。

初期実装では、ブロック本体のテクスチャを動的変更するより、専用GUI内で描画する方針が現実的である。

削りミニゲームは本MODの特徴になり得る一方、実装負荷が高い場合は簡略化または後回しにする。

具体的な作業台、ミニゲーム、レシピ体系は未決定である。

## 11. 経済システムにおける役割

本MODは、プレイヤー間取引の対象となる高付加価値品を増やす役割を持つ。

主な供給関係：

| プレイヤー | 主な供給物 |
|---|---|
| 探検家 | 希少植物、地域素材、専用鋳型、ダンジョンの発見物 |
| 冒険者 | ボス素材、戦闘報酬、高難度ダンジョン素材 |
| 食料生産者 | 高品質作物、畜産物、料理材料、保存食、各ロール向けバフ料理 |
| 鍛冶師 | ボス装備、武器部品、防具、修理・再加工 |
| 錬金術師 | ポーション、薬品、戦闘用消耗品 |

食料生産者は食料インフラを担うため、比較的安定した収入を得やすい。農耕・畜産による材料供給に加え、保存食と各ロール向け料理によって継続的な需要を作る。

そのため、経済全体ではガチャ、装飾、コスメ、土地、ダンジョン挑戦費、装備製造費など、本MOD外も含めた通貨の消費先が必要になる。

本MOD単体ですべての経済問題を解決するのではなく、専門職間の取引材料と消耗品需要を増やすことを主目的とする。

## 12. 他MODとの役割分担

### Pufferfish's Skills

- スキルツリーと成長要素を担当
- 本MODの生産行動や品質判定と接続

### Create

- 大量生産
- 原料生産
- 物流
- 食料生産者スキル補正なしの品質で生産する自動化許可品

食料生産者関連レシピでは`automation_policy`を使用し、MVPでは保存食に必要な切断・乾燥と保存食Iの混合だけを自動化可能にする。調理前素材セット、保存食II～V、各ロール向け料理などの`manual_only`レシピは、Createだけで全工程を完結させない。

### Diet

- 食品の種類に継続的な需要を作る
- 食料生産者の生産物が一種類へ偏ることを防ぐ
- 任意依存とし、未導入または無効な場合も食料生産者機能を動作させる

### Cataclysm / Twilight Forest など

- ボス、ダンジョン、戦闘、希少素材を担当
- 本MODは素材加工と装備製造を担当

### Lightman's Currency

- プレイヤー間取引や店舗を担当
- 本MODの高品質品・装備・料理の販売に利用

## 13. 技術的な主要要素

実装が必要になる主な要素は以下のとおり。

- 独自アイテム
- 独自ブロック
- Block Entity
- 専用GUI・メニュー
- 時間経過型の加工処理
- 独自レシピタイプ
- 品質データの保存
- 品質別スタック管理
- 品質低下時間と保存倍率の計算
- 耕地の肥沃度と作物ごとの成長時間
- 牧畜ブロックによる範囲・給餌・容量・成長管理
- バイオームへの独自作物生成（バニラ作物の実装・プレイテスト後）
- 他MODバイオームへの生成（独自作物追加時）
- Pufferfish's Skills API連携
- プレイヤー操作を要求する加工処理
- ミニゲームのクライアント描画
- サーバー側での結果検証
- 他MOD素材・装備との互換レシピ
- JSONやデータパックによるレシピ定義
- レシピごとの`automation_policy`

特に、ミニゲームの入力結果や品質判定は、クライアント任せにせずサーバー側で検証する必要がある。

## 14. 現時点での確定事項

- 生活・生産系行動をPufferfish's Skillsへ接続する
- 農耕、畜産・酪農、料理、鍛冶、探索を主要分野とする
- 探検家は戦闘職ではなく、フィールド巡回・発見・採取を中心とする
- 農耕、畜産・酪農、料理は食料生産者として1つのスキルツリーへ統合する
- 食料生産者は農耕、畜産・酪農、料理の3分岐で構成する
- ポーション・錬金も追加候補に含める
- Createは弱体化せず、大量生産担当として残す
- 食料生産者ではレシピごとに自動化可否を定義し、上位料理はプレイヤーの開始操作を要求する
- 新規作物を追加する構想を維持し、初期対象のバニラ作物を実装・プレイテストした後に新規作物の実装へ進む
- 新規作物は、特定バイオームや他MODバイオームへの野生生成を候補とする
- 食料生産者の品質は高品質、標準品質、低品質、腐敗の4状態とする
- アイテムごとの個別タイムスタンプは使用しない
- 食料生産者の品質低下はスタック単位の残り時間と保存倍率で管理する
- 装備は固定レシピ・固定アイテム方式とする
- ボス装備には専用中間パーツや専用鋳型を使用する
- 専用鋳型はダンジョン報酬として入手させる
- 鍛冶は複数工程に分ける
- 3か月の運営期間で遊び切れない程度の生産・冒険ループを目指す
