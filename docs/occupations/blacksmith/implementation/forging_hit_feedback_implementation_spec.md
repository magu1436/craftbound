# 鍛造GUI 打撃演出 実装仕様書

## 目的

鍛造ミニゲームで打撃した際に、視覚的な手応えを追加する。

本機能は**クライアント側だけの表示演出**とし、打撃強度、打撃履歴、品質、破損判定などのゲーム状態には影響させない。

## 対象

主な変更対象:

```text
ForgingScreen
```

必要に応じて、鍛造GUI内の描画処理を小さなprivateメソッドへ分離してよい。

新しいPacketやサーバー側処理は追加しない。

---

## 1. 打撃時の即時演出

プレイヤーが有効な打撃領域を左クリックし、`ForgingStrikeRequestPacket` を送信するタイミングで、クライアント側の打撃演出を開始する。

サーバー応答は待たない。

```text
打撃領域を左クリック
    ↓
クライアント
    ├─ 打撃演出開始
    └─ ForgingStrikeRequestPacket送信
```

演出は表示専用とする。

---

## 2. 振動演出

`ForgingScreen` に短時間の振動状態を保持する。

概念例:

```java
private int hitShakeTicks;
```

打撃時:

```java
hitShakeTicks = 4;
```

4tick程度で自然に終了させる。

振動量は最大でおおむね、

```text
X: -2 ～ +2 px
Y: -1 ～ +1 px
```

とする。

毎フレーム完全な乱数を使用してもよいが、振動中に位置が大きく飛ばないようにする。

### 描画対象

振動させる対象:

```text
加工中パーツ
鍛造作業領域
打撃時の火花などの演出
```

必要ならゲージもわずかに振動させてよい。

振動させない対象:

```text
完成ボタン
GUI外枠
ツールチップ
その他クリック可能なWidget
```

`GuiGraphics#pose()` の `pushPose / translate / popPose` を利用し、**クリック判定座標そのものは変更しない**。

概念例:

```java
graphics.pose().pushPose();
graphics.pose().translate(shakeX, shakeY, 0);

renderForgingArea(graphics);

graphics.pose().popPose();
```

---

## 3. パーツ沈み込み

打撃開始直後だけ、加工中パーツの描画位置を下方向へ移動する。

目安:

```text
打撃直後: +2px
次tick:   +1px
以降:      0px
```

振動とは独立した値として計算してよい。

ItemStack自体やBlockEntity内の状態は変更せず、`ItemRenderer`へ渡す描画座標だけ変更する。

---

## 4. 既存演出との併用

打撃時には既存方針どおり、

```text
ANVIL_HIT系の打撃音
既存Minecraftパーティクル
```

と併用する。

危険状態では既存仕様の、

```text
鈍い打撃音
危険通知用パーティクル
```

を優先する。

今回の振動・沈み込み演出は危険状態でも維持する。

専用Texture、専用アニメーション画像、新規SoundEventは追加しない。

---

## 5. サーバー拒否時

振動・沈み込みは即時クライアント演出のため、後からサーバーが打撃要求を拒否してもロールバックしない。

ただし以下はサーバー同期済み状態を正とする。

```text
打撃履歴
打撃回数
ゲージ状態
破損状態
品質
完成状態
```

演出によってこれらを更新しない。

---

## 6. 実装上の制約

- ワールドカメラ自体を揺らさない
- Minecraft本体のカメラ状態へ干渉しない
- Widgetの実クリック領域を移動させない
- 打撃1回ごとに新しいTextureやオブジェクトを生成しない
- サーバーへ演出専用Packetを送らない
- 描画演出を `ForgingGameService` に実装しない
- `ForgingScreen` のクライアント表示責務として完結させる

---

## 受け入れ条件

- 打撃領域を左クリックすると即座に短い振動が発生する
- 加工中パーツが一瞬下方向へ沈む
- 約4tick後には通常位置へ戻る
- 完成ボタンなどのWidgetは振動しない
- 振動中でもWidgetのクリック判定位置がずれない
- 打撃以外のGUIクリックでは演出が発生しない
- 演出の有無によって打撃強度や採点結果が変化しない
- 通信遅延があってもクリック直後に演出が開始する
- サーバー側コードに演出専用状態を追加しない
