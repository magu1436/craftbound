# 鍛冶システムテスト仕様

## 1. 本書の目的

本書は、[鍛冶師システム仕様](./blacksmith.md)、[鉄のピッケル試作仕様](./iron-pickaxe.md)、[鍛冶素材仕様](./materials.md)、[鍛冶システムJSON・評価関数仕様](./data-formats.md)、[鍛冶システムUI仕様](./ui.md)、[鍛冶ライフサイクル仕様](./lifecycle.md)に対するMVPのテストケースを定義する。

仕様値を変更した場合は、固定値を前提とするテストデータも同じ変更で更新する。評価関数の境界、状態遷移、素材消費、不正操作の拒否は自動テストを必須とする。

---

## 2. テスト区分

| 区分 | 対象 |
|---|---|
| 単体テスト | JSON検証、評価関数、品質計算、形状変換、入力経路補間 |
| 統合テスト | Block Entity、メニュー、レシピ、アイテムデータ、保存と再開 |
| ゲームテスト | 右クリック操作、ブロック破壊、複数プレイヤー、MOD連携境界 |

1秒は20ゲームティックとして扱う。時間境界は、境界の1ティック前、境界値、境界の1ティック後を原則として検証する。

## 14. MVP完了条件

MVPでは、本書の全ケースが成功することを受け入れ条件とする。専用のひび・亀裂オーバーレイは条件付き機能であり、未実装でも音、既存パーティクル、GUI枠の色変化に関するケースが成功すればMVPを満たす。
