# 食料生産者（FoodProducer）文書案内

このフォルダはFoodProducer固有の仕様、アセット、判断事項およびテストを管理する。最初にこの文書から目的別の正本を選ぶ。

## 文書一覧

| 文書 | 正本とする内容 | 更新する場面 |
|---|---|---|
| [ゲーム仕様](foodproducer.md) | ゲーム内挙動、現在採用する数値、レシピ、スキル、連携規則 | プレイヤーが体験する仕様を変更するとき |
| [アセット仕様](assets.md) | Block・Item ID、モデル、Texture名、見た目、制作範囲 | アセットの追加・変更・差し替え時 |
| [判断台帳](decisions.md) | 初期値、未決定、外部待ち、MVP後へ送った項目 | 仮決定を正式化または再検討するとき |
| [テスト・受け入れ基準](test-cases.md) | 機能別の合格条件、実施状況、統合テスト | 実装検証とMVP完了判定時 |

## 参照する共通文書

- MOD全体の役割は[Craftbound概要](../../overview.md)を参照する。
- 全職業共通の状態管理、識別子、復旧規則は[職業共通仕様](../common.md)を参照する。
- Pufferfish's Skillsのデータ形式は[Pufferfish's Skillsメモ](../../pufferfishs-skills.md)を参照する。

共通仕様とFoodProducerゲーム仕様が競合する場合はFoodProducerゲーム仕様を優先する。他職業の仕様書はFoodProducer文書の正本にせず、職業間の接続条件だけをFoodProducer側へ記録する。

## 記載しない情報

- 会話中だけの作業予定やブランチ操作はゲーム仕様へ記載しない。
- テストの成否はゲーム仕様へ混ぜず、テスト・受け入れ基準へ記録する。
- 仮決定や外部職業待ちは確定仕様へ混ぜず、判断台帳から該当仕様節を参照する。
- Java、JSON、モデルファイルは実装結果であり、文書と不一致なら推測でどちらかを正本にしない。
